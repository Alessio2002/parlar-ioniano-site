# Deployment Path – Parlar Ioniano

The deployment lifecycle of the portal follows a rigorous progression from local execution to global production:

1. **Localhost:** Developed and tested locally via `http://localhost:8000` or Live Server to validate JSON fetching and JavaScript modules.
2. **Local Area Network (LAN):** Tested across local mobile devices via smartphone hotspot connection to ensure responsive layout behavior under real network conditions.
3. **GitHub Pages (Production):** Automatically deployed over HTTPS via GitHub Pages at [https://alessio2002.github.io/parlar-ioniano-site/](https://alessio2002.github.io/parlar-ioniano-site/).
